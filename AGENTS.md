# AGENTS.md — инструкции для ИИ-агентов и разработчиков

Сначала прочитай `README.md`. Здесь — правила, которые легко нарушить.

## Контекст в одном абзаце

Cloudflare Worker (JS, ES-модули, без сборки) ищет заказы на **всё, что связано с видео** (ИИ-видео/UGC, монтаж,
моушн-дизайн, анимация, YouTube-монтаж) на Freelancer.com, PeoplePerHour, YT Jobs, Freelancehunt и Kwork, оценивает
их 0–100 и присылает в Telegram владельцу с готовым откликом. **Приоритет — иностранные заказчики**: местные
(Kwork, Freelancehunt в гривнах) только в сводке, после иностранных. Данные — D1 (`DB`). Отдельный аккаунт
Cloudflare (не тот, где `rostock-wohnung-bot` и `iphone-alert-bot`). Владелец общается по-русски; тексты бота —
по-русски, отклики — на языке заказа (англ. / рус. для Kwork / укр. для Freelancehunt).

## Правила владельца (не менять без явной просьбы)

- **Бот не отправляет отклики сам** — только готовит текст; откликается владелец (правила бирж, риск блокировки).
- **Не обходить защиту сайтов** (Guru, Workana, Mandy, Behance отвечают 403 — не подключены; Upwork/Fiverr — тоже).
- **В откликах нигде не упоминать уровень английского и страну проживания.** Только переписка — без созвонов.
- Бесплатный тестовый ролик 5–10 с предлагается только в сильных заказах (score ≥ 65).
- Не коммитить секреты (токен, `RUN_KEY`, `WEBHOOK_SECRET`, Chat Id, API-токен Cloudflare в `.env`).

## Ограничения платформы

1. **10 мс CPU на запуск.** Один источник за запуск (`CYCLE` в `src/index.js`). Оцениваются только новые заказы.
   В `src/score.js` **не используй `\p{L}` и флаг `u`**: Unicode-классы компилируются ~90 мс на холодном старте —
   буквы задаются явным диапазоном `LETTER`, текст заранее в нижнем регистре.
2. **Именованные экспорты в `src/index.js` запрещены** — workerd считает их обработчиками и не стартует.
3. Не больше ~5 сообщений в Telegram за запуск (`MAX_SENDS_PER_RUN`), лимит подзапросов.
4. Cron: 2 из 5 (`wrangler.toml`).

## Как вносить изменения

- Новый источник: функция `fetchX` в `src/sources.js` (общий формат заказа описан в начале файла) → запись в
  `SOURCES` → место в `CYCLE`. Первый проход источника молчаливый (`health.baseline`).
- Пороги и слова — только в `src/score.js` (`HOT_SCORE`, `GOOD_SCORE`, `LOCAL_GOOD_SCORE`, `CATEGORIES`, `RED_FLAGS`).
- Тексты откликов и подбор работ из портфолио — `src/proposal.js` (работы как на сайте портфолио).
- Команды Telegram — `COMMANDS` в `src/commands.js` → после публикации `GET /setup?key=…`.
- Схема D1 — `db/schema.sql` (+ миграция при изменении существующих таблиц).

## Проверка перед «готово»

```bash
for f in src/*.js scripts/*.js; do node --check "$f"; done
npm run check                               # все источники + оценка, без Telegram/D1
npx wrangler dev --local                    # затем GET /run?key=local-test&dry=1 (локальная D1: d1 execute --local)
npm run deploy && npm run tail              # cron: outcome ok, cpuTime ≈ ≤ 10–15 мс
```
